3 处
永乐宫必看旺季限流
国保 ｜ 元代《朝元图》壁画 · 中国壁画巅峰
👀 重点看：三清殿《朝元图》——286 尊神祇列队朝拜，主像高过 2 米、色彩 700 年不褪；纯阳殿连环画式叙事壁画、重阳殿看王重阳生平。
三清殿 ·《朝元图》元代壁画巅峰▾
东壁"东华帝君"、西壁"西王母"各领一列，前后共 286 尊。先抓两列主像的排布，再回头细看神祇的服饰与持物。
机位殿内禁拍照、需套鞋套；出殿后的临摹室可拍高清摹本
纯阳殿 · 重阳殿连环画式叙事壁画▾
纯阳殿画吕洞宾生平（连环画式分幅），重阳殿画王重阳与全真七子。看的是"怎么把一整套故事铺满一整面墙"。
实用预约 / 限流 / 鞋套▾
预约景区公众号 / OTA 确认，旺季常限流
禁忌殿内禁拍照、需套鞋套

春秋楼明代"吊柱"悬空回廊▾
二层回廊的柱子不落地，靠上层梁架悬挑——这是全庙建筑技术含量最高的一处，抬头看廊下与梁架交接。
崇宁殿 · 琉璃影壁主殿与庙前照壁▾
崇宁殿是主殿，看殿前石雕与蟠龙柱；出来别急着走，庙前琉璃影壁的琉璃构件在顺光时最好看。

  • 打底短袖 / 薄长袖 ×2–3（白天单穿）
  • 中层薄卫衣 / 针织 ×1
  • 外层防风外套（冲锋衣 / 夹克）— 早晚与山里最关键
  • 加厚薄羽绒马甲（怕冷就塞一件）

下装 + 鞋

  • 长裤×2（山里、祠庙里都方便）
  • 鞋舒适防滑运动鞋 — 浊漳河谷、开化寺长石梯、大粮山全靠走

必带小物

  • 防雨折叠伞 / 一次性雨衣
  • 防晒帽子、墨镜、防晒霜（紫外线强、极干）
  • 保湿润唇膏、护手霜
  • 日用保温杯、充电宝、现金零钱、口罩、小背包
  • 证件身份证（火车 / 景区 / 预约全靠它）

进殿注意

  • 禁彩塑 / 壁画区禁闪光灯，多数禁拍照（玉皇庙二十八星宿、铁佛寺尤严）
  • 礼部分殿内需脱帽；个别点位要换鞋套
穿衣按「洋葱式」三层最稳；山西深秋昼夜温差大、多秋雨，出发前 1 天再看一次天气。
