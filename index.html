天气判断

20–26℃白天（午后偏热）
10–14℃早晚
-3~-5℃山区/河谷再降
昼夜温差多地可达 15℃ 以上；国庆期间山西多秋雨。晋东南（长治/晋城）比运城、临汾平原再凉 3–5℃。

上衣：洋葱式三层

  • 打底短袖 / 薄长袖 ×2–3（白天单穿）
  • 中层薄卫衣 / 针织 ×1
  • 外层防风外套（冲锋衣 / 夹克）— 早晚与山里最关键
  • 加厚薄羽绒马甲（怕冷就塞一件）

下装 + 鞋

  • 长裤×2（山里、祠庙里都方便）
  • 鞋舒适防滑运动鞋 — 浊漳河谷、开化寺长石梯、大粮山全靠走

必带小物

  • 防雨折叠伞 / 一次性雨衣
  • 防晒帽子、墨镜、防晒霜（紫外线强、极干）
  • 保湿润唇膏、护手霜
  • 日用保温杯、充电宝、现金零钱、口罩、小背包
  • 证件身份证（火车 / 景区 / 预约全靠它）

进殿注意

  • 禁彩塑 / 壁画区禁闪光灯，多数禁拍照（玉皇庙二十八星宿、铁佛寺尤严）
  • 礼部分殿内需脱帽；个别点位要换鞋套
